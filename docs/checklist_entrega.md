# Checklist final de entrega

- [ ] `docker compose config` sin errores.
- [ ] `docker compose up --build` inicia DB, API y web.
- [ ] `/health` devuelve estado de API y base de datos.
- [ ] Registro y login funcionan con bcrypt y JWT expirado.
- [ ] API no publica el puerto 8000.
- [ ] CSP, SRI y cabeceras de seguridad verificadas.
- [ ] Banco contiene 200+ preguntas sin duplicados exactos.
- [ ] Pre-test y post-test muestran mejora por tema.
- [ ] Tutorial, audio, logros, comodines y pantalla final probados.
- [ ] Dificultad adaptativa y repetición de falladas verificadas.
- [ ] Mentor muestra pista, fuente y no revela la respuesta.
- [ ] Laboratorio vulnerable ejecutado únicamente en localhost.
- [ ] Pruebas automáticas pasan.
- [ ] Informe CVSS incluye evidencia antes/después.
- [ ] Diagramas Mermaid y guion de demo incluidos.
