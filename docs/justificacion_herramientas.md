# Justificación de herramientas

| Herramienta | Justificación |
|---|---|
| Python + FastAPI | API tipada, validación clara y buena base para pruebas automáticas. |
| MySQL + SQLAlchemy | Persistencia relacional del usuario, progreso y evaluaciones sin concatenar SQL. |
| Phaser | Movimiento, colisiones y feedback visual/sonoro en navegador sin instalar cliente. |
| Docker Compose | Reproduce API, base de datos y web en la demo de evaluación. |
| Nginx | Sirve el frontend, centraliza el proxy y aplica cabeceras de seguridad. |
| Mermaid | Diagramas versionables para arquitectura, flujo y defensa. |

La selección prioriza herramientas conocidas, reproducibles y suficientes para
un MVP educativo. El mentor usa fuentes curadas locales para evitar respuestas
inventadas; una integración RAG externa puede añadirse sin hacer depender la
demo de un servicio de terceros.
