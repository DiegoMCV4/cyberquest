# Guion de demo de 5 minutos

1. **0:00–0:40 — Contexto:** explicar la brecha ficticia y los cuatro temas.
2. **0:40–1:20 — Acceso:** registrar jugador y mostrar el tutorial inicial.
3. **1:20–2:20 — Aprendizaje:** combatir un enemigo, responder, observar explicación,
   XP, dificultad y repetición de una pregunta fallada.
4. **2:20–3:10 — Evaluación:** ejecutar pre-test, abrir un modo especial y mostrar
   el mentor con una fuente citada.
5. **3:10–4:10 — Seguridad:** enseñar el laboratorio vulnerable, ejecutar el reto
   local y comparar la instancia vulnerable con la corregida.
6. **4:10–5:00 — Evidencia:** mostrar post-test, mejora por tema, logros,
   arquitectura, pruebas y mitigaciones CVSS.
